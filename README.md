## Projeto em destaque

### [Sistema de Votação Cooperativista](https://github.com/ediklecio/DESAFIO-DB-votacao-fullstack)
*Desafio técnico, projeto pessoal*

- **Problema:** cooperativas precisam cadastrar pautas, abrir sessões de votação com prazo e garantir que cada associado vote uma única vez.
- **Solução:** API REST + SPA. O voto único é garantido por constraint no banco, não só pela aplicação. Inclui apuração parcial e final (aprovada, rejeitada ou empate), migrações versionadas com Flyway, decisões técnicas documentadas, Swagger e ambiente completo com Docker Compose.
- **Tecnologias:** Java 25 · Spring Boot 4 · PostgreSQL · Flyway · React 19 · Tailwind CSS · Docker Compose
- **Código:** [github.com/ediklecio/DESAFIO-DB-votacao-fullstack](https://github.com/ediklecio/DESAFIO-DB-votacao-fullstack)
